# NeonClaim

A land claiming and anti-griefing plugin for Paper, Folia, and Spigot Minecraft servers, powered by NeonJava.

## 🌟 Features

- 🏡 **Land Claiming & Protection**: Allow players to claim land areas, prevent griefing, and manage trust lists.
- ⚡ **Folia & Paper Ready**: Optimized for multi-threaded Folia regions and Paper servers.
- ⚙️ **Configurable Limits & Rules**: Customize claim block accumulation, siege settings, and claim expiration rules.

---

## 🛠️ Installation

1. Download `NeonClaim.jar`.
2. Place it in your server's `plugins/` directory.
3. Restart or reload your server.

---

## 📦 Building from Source

Requirements: **JDK 21** & **Maven**.

```bash
git clone https://github.com/neonjava/neon-claim.git
cd neon-claim
mvn clean package
```

The output `.jar` will be saved in `target/`.
